Source graph starts selected analysts in parallel, converges at Evidence Weigher, joins optional Memory Log before debate, then Research Manager → Trader → risk debate → PM. The native workflow is conversational orchestration and must label `ORIGINAL_GRAPH_EXECUTED=false` and `EXECUTION_PARITY=NOT_CERTIFIED`.

Validation on each run: (1) seven individual evidence records; (2) every original source block attempted or explicitly unavailable; (3) exact evidence arithmetic and overlap cap; (4) debate turn count/order and final five-tier output; (5) zero Render calls; (6) source/date/coverage audit; (7) missing source fail-close. Passing static prompt checks does not certify model equivalence, external data completeness, or historical memory parity.
